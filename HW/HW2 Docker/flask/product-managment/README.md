# Product Management - SnickerSync

- Goal: Create a enaging and interactive syncing process that allows users to experience a "snicker" during their syncs.
- Non-Goal: End-users having customization options for different ways to snicker at things (specific memes, audios, etc.)
    - Non-functional Requirement 1: Access Control
        - Functional Requirements:
            - PM's will be premptively given admin controls through backend 
            - PM's have a interface to give other users more permissions through UI friendly panel
    - Non-functional Requirement 2: Maintaing Concepts
        - Functional Requirements:
            - A admin exclusive interface that allows PM's to add, remove, or update snickering concepts that will be stored/updated in a database
            - A history flow chart that shows all changes to concepts, track modifications, and ability revert to prior versions if needed
