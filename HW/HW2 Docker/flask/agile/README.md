- Theme: Get GiggleGit demo into a stable enough alpha to start onboarding some adventurous clients
- Epic: Onboarding experience

    - Task: Make the merge process easier and enjoyable.
        - Ticket 1: Simplify the merge process with a easily digestable interface
            - Connect specific error merge messages to memes with a caption under that specifies the problem while still being relevant to the meme
        - Ticket 2: Integrate engaging animations to enhance the merge experience
            - Implement a user-friendly UI that utilizes a meme API to display funny gifs/images based on whether a merge is successful or not

This is not a user story. Why not? What is it? "As a user I want to be able to authenticate on a new machine"

User stories typically focus on a benefit or value as opposed to functionality. In this description, the user only asks for more technical related needs as opposed to emotional gains/pains, which takes away the point of a user story. Moreover, there is a lack of prior experience that the user have, causing for a lack of depth in the character. This resembles more of a requirement/task than really a user story.
